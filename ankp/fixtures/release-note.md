# ExampleAI Platform v2.4.0 Release Notes

Published: 2026-07-10

## New Features

- ExampleAI Platform v2.4.0 adds structured output validation for tool calls.
- ExampleAI Platform v2.4.0 introduces a model routing API with per-task budgets.

- The legacy completion endpoint /v1/complete is deprecated and will be removed in v3.0.

## Security

- ExampleAI Platform v2.4.0 fixes a prompt handling issue in the document loader rated high severity.
